# Local data

The offline synthetic demo uses committed `demo_race.csv` and `track.json`. `demo_race.csv` is one row per car/timestamp; the exact columns and validation rules are in [data contracts](../docs/DATA_CONTRACTS.md). `scenarios/` contains six historical manifests, source notes, and clearly simulated portable fallback motion. The Canada and Qatar fallback positions use committed scenario-specific track geometry. FastF1-derived processed feeds are optional local files ignored by Git; see [historical methods](../docs/HISTORICAL_SCENARIOS.md). Keep private uploaded images in ignored `data/uploads/`; do not commit them. Regenerable large synthetic tables can live in ignored `data/synthetic/`.
