# Local data

The offline synthetic demo uses committed `demo_race.csv` and `track.json`. `demo_race.csv` is one row per car/timestamp; the exact columns and validation rules are in [data contracts](../docs/DATA_CONTRACTS.md). `scenarios/` contains four historical manifests, source notes, clearly simulated portable fallback motion, and user-provided incident stills with reviewed observations in `visual_features.json`. The Canada and Qatar fallback positions use committed scenario-specific track geometry. FastF1-derived processed feeds are optional local files ignored by Git; see [historical methods](../docs/HISTORICAL_SCENARIOS.md). Keep private uploaded images in ignored `data/uploads/`; do not commit them. Regenerable large synthetic tables can live in ignored `data/synthetic/`.
